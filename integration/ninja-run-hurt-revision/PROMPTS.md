# Ninja Hỏa — nguồn sửa run/hurt

Công cụ: image_gen tích hợp; hai lượt tạo ảnh riêng, nền alpha. Tham chiếu danh tính: idle-reference.png cắt nguyên frame Idle đầu từ atlas production (4,4,384,320). Tham chiếu chuyển động đã xem: electric-wolf/animation/locomotion-contact.png và boss-khan/animation/hurt-contact.png. Không dùng hai nhân vật này làm thay thế danh tính Ninja.

## Run

Create a transparent game sprite animation sheet using attached Flame Ninja idle as STRICT identity, anatomy, costume, palette and rendering reference. Illustrated textured pixel art, detailed 2D side-view game sprite facing RIGHT. Adult muscular red/black ninja, red long scarf streaming left, black hood and lower face mask, bare muscular upper arms, black padded sleeveless outfit with red trim, baggy dark trousers, metal shin guards, sword sheathed at left hip. EXACTLY 8 frames in a clean 4 columns x 2 rows grid, equally sized cells, no text, no guide lines, no ground shadows. Smooth natural RUN cycle in place: right foot contact, compression, passing, flight, LEFT foot contact, compression, passing, flight. Clearly alternate legs and counter-swing arms, near/far limbs shaded consistently, do NOT mirror the entire character. Stable head size and torso proportions across all 8 frames, mild forward lean held constant, bob only subtly. Scarf secondary motion follows smoothly. Match reference idle's physical body scale, NEVER bulk up the head shoulders torso, no chibi or redesign, no sword drawn, no effects. In each cell place feet on SAME baseline at 90% cell height, hip centered at 50% cell width, fully contain scarf. Target character standing equivalent height 78% cell height. Need 1536x640 sheet if possible, 384x320 cells. Actual transparent alpha background. Frame 8 must loop naturally into frame 1. Only this run sheet; do not include idle or other moves.

## Hurt

Use case identity-preserve. Create a NEW transparent 2D game HURT / RECOVERY sprite sheet of EXACTLY this Flame Ninja from supplied idle reference. Same illustrated textured pixel art, same face hood red scarf black/red clothing, sheathed sword, adult muscular body. Strict same head, neck, shoulder width, torso, arm and leg anatomical dimensions as idle reference. DO NOT ENLARGE THE CHARACTER when hurt. Four equal 384x320 cells arranged 2 columns x 2 rows (768x640 target): 1) initial hit reaction: torso recoils a little, head turns slightly back, feet planted; 2) absorb impact: chest bends slightly forward, left forearm guarding belly, knees modestly flexed, no deep crouch or knockdown; 3) recover balance: torso rises, hands return to neutral; 4) almost identical to reference idle ready pose to transition smoothly. All facing RIGHT with consistent three-quarter side view. Foot baseline 90% cell height, pelvis at same X 50% cell width; head top standing equivalent 12% cell height. Preserve fixed anatomical scale in all frames, same shoulder mass and head diameter as reference. No muscle inflation, no zoom, no exaggerated scarf enlargement. Entire body inside each cell, no clipping. Actual alpha transparent background, no colored backdrop, no shadows, no VFX, no labels or cell lines. Only four hurt/recovery poses. Do not include other character moves.
